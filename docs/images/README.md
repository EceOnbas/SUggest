# Images loaded over the network

Files here are **not** bundled with the app. The app downloads them from
GitHub at runtime with `Image.network`, so they count as network images.

| File | Used on | Credit |
|---|---|---|
| `welcome_campus.jpg` | Welcome screen, top band | Photo: Beren Güler, Sabancı University campus, March 2024 |

The Welcome screen shows the sakura branch while the photo loads, and
keeps the branch if there is no internet.
